# StreetLights

**Find out what's happening with Richmond's infrastructure projects**

StreetLights is a web app made for the Hack For RVA in March 2026. Search an address to find nearby road, utility, school, park, and other public projects around Richmond, Virginia.

**[Open the live demo](https://a-aquiro.github.io/Streetlights/)**

## About StreetLights

Project information about local construction exists, but it's hard to find and often filled with technical terms. StreetLights brings Richmond's Capital Improvement Plan projects together on a map and explains them in a way that everyday citizens can understand.

Search for a Richmond address and find information about what the project is and when it's expected to be finished.

## Features

- Search an address and find projects nearby
- Explore projects on an interactive map
- Filter projects by category
- Check project details such as budgets, timelines, and manager contact information
- Report local infrastructure issues and upvote reports from other residents
- Usable GUI on desktop or mobile

## Built With

**Frontend:** React, TypeScript, and Vite

**Map:** Leaflet and React Leaflet

**Styling:** Tailwind CSS

**Project data:** City of Richmond CIP Dashboard

StreetLights is a working prototype, not an official Richmond City service.
